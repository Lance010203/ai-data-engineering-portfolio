# Bond Default Risk Dynamic Prediction

## Project Overview

This project focuses on dynamic bond default risk prediction using machine learning methods. It integrates financial indicators, market variables, macroeconomic variables, and media attention features to construct a multi-source default risk prediction framework.

## Research Design

The project compared traditional and machine learning models, including:

- Logit
- Random Forest
- XGBoost

An expanding-window prediction framework was used to simulate a dynamic prediction setting.

## Data and Features

The feature system included:

- Firm-level financial indicators
- Market variables
- Macroeconomic variables
- Media attention features

## Modeling and Evaluation

The models were evaluated using:

- Accuracy
- Precision
- Recall
- F1-score
- AUC

## Key Focus

The project focused on:

- Multi-source data integration
- Dynamic prediction window design
- Model comparison
- Performance evaluation
- Interpretation of default risk prediction results

## Notes

This project is based on my undergraduate thesis. Due to data source restrictions, raw data is not uploaded. This repository only presents the research design and summarized workflow.
