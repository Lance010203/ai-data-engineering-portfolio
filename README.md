## 2. Project Experience

### Meituan Delivery Overtime Prediction

This project focused on identifying high-risk overtime orders in an instant delivery scenario.

The workflow included data cleaning, time-based feature engineering, distance-related feature construction, model training, and model evaluation.

Key tasks:

- Cleaned and processed large-scale order-level delivery data
- Constructed features such as dispatch delay, grab response time, fetch waiting time, and delivery duration
- Built a binary classification model to identify potential overtime orders
- Evaluated model performance using AUC, Precision, Recall, F1-score, and confusion matrix

### Bond Default Risk Prediction

This project focused on dynamic bond default risk prediction using machine learning models.

The workflow included multi-source feature construction, model comparison, and expanding-window prediction design.

Key tasks:

- Integrated financial indicators, market variables, macroeconomic variables, and media attention features
- Compared Logit, Random Forest, and XGBoost models
- Designed an expanding-window framework for dynamic prediction
- Evaluated model performance using Accuracy, Precision, Recall, F1-score, and AUC
